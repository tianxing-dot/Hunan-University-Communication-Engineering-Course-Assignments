# 图书馆管理系统

用 C++ 实现的命令行图书馆。访客可以浏览馆藏，读者登录后可以查书、借书和还书，管理员负责维护书目和读者账户。

## 实验要求

- 用类表示图书、账户和图书馆。图书应记录题名、ISBN 或 ISSN、作者、出版社和价格。用外部文件存储书目、馆藏、借阅记录和用户信息，自行准备测试数据。
- 在文字菜单中提供注册、登录和返回上一级的入口。管理员应能增删改查图书和读者账户，并能把读者密码重置为题目指定的默认值 `123456`。
- 读者应能按题名或书号精确查找一本书，按作者查找其全部作品，并按题名字典序显示。借书后应能查看和归还所借图书。
- 分别列出借阅次数最多的十本书和最新出版的十本书。可选拓展包括根据相似借阅记录推荐图书，以及改进检索速度和交互体验。

## 编译与运行

在本目录打开 Windows PowerShell，使用支持 C++11 的 MinGW 编译器执行以下命令。程序在启动目录读取和保存两个数据文件。

```powershell
g++ -std=c++11 -finput-charset=UTF-8 -fexec-charset=UTF-8 main.cpp Book.cpp Library.cpp Menu.cpp -o LibrarySystem.exe
.\LibrarySystem.exe
```

也可以用 Dev-C++ 打开 `LibrarySystem.dev`。源码和数据文件均采用 UTF-8 编码。

| 演示身份 | 账号 | 密码 |
| --- | --- | --- |
| 管理员 | `demo_admin` | `demo-admin` |
| 读者 | `demo_reader` | `demo-reader` |

从主菜单选 `1` 登录；选 `2` 可直接浏览。试用读者账号时，可用书号 `9787010121208` 搜索、借阅，再在同一次登录中归还。演示数据包含 116 条书目，作者使用分组代号，借阅计数从零开始。

## 数据与实现

`Book` 负责一条书目的读写，`User`、`Admin` 和 `Reader` 表示不同身份，`Library` 管理数据和借阅操作，`Menu` 负责输入与菜单跳转。[实验报告原文（Word）](图书馆管理系统实验报告.docx) · [内容摘要](实验报告.md)

| 文件 | 每行字段，依次用竖线分隔 |
| --- | --- |
| `books_data.txt` | 题名、书号、作者组、出版社、出版时间、价格、累计借阅次数 |
| `users_data.txt` | 账号、演示密码、角色、累计借阅数、当前借阅书号列表 |

原实现会保存当前借阅书号，但重启时只恢复读者的累计借阅数。因此，重启后查询在借书目和还书有此限制。
